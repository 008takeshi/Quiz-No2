---
description: サーバー起動からBotを使ってフルゲームフローを自動テスト
---

開発サーバーを起動し、Bot プレイヤーで全フェーズを通してゲームフローをテストします。

## 使い方

```
/full-game-test [--room ROOM_CODE] [--players N] [--mode random|correct|wrong]
```

| 引数 | 説明 | デフォルト |
|---|---|---|
| `--room` | 既存のルームコード（省略時はユーザーに作成してもらう） | なし |
| `--players` | Bot台数 | 5 |
| `--mode` | Bot回答モード | random |

## 手順

### ステップ 1: サーバー起動確認

```bash
curl -s http://localhost:3000/health
```

- 応答があれば起動済み（次のステップへ）
- 応答なしなら「先に `/dev-server` でサーバーを起動してください」と案内して終了

### ステップ 2: ルーム準備

`--room` 引数がある場合はそのコードを使う。ない場合は：
- ユーザーに「ホスト画面（http://localhost:5173/host）でルームを作成し、ルームコードを教えてください」と案内する
- ルームコードを受け取ったら次へ進む

### ステップ 3: Bot参加（バックグラウンド実行）

```bash
npx tsx scripts/bot-players.ts --room <ROOM_CODE> --count <players> --mode <mode>
```

### ステップ 4: テスト手順をユーザーに案内

Bot 接続後、以下の操作手順をホスト画面で実行するよう案内する：

```
テスト手順（ホスト画面で操作）:
1. ✅ [テンプレート選択] → 任意のテンプレートを選択
2. ✅ [ゲーム開始] → Bot N 人が参加したことを確認
3. ✅ [イントロ表示] → 演出を確認
4. ✅ [問題準備] → QUIZ_PREPARE 画面を確認
5. ✅ [問題表示] → 問題・画像・選択肢の段階表示を確認
6. ✅ [回答開始] → タイマー動作・Bot 回答カウントを確認
7. ✅ [締切] → QUIZ_CLOSED 後の結果表示を確認
8. ✅ [得票数表示] → 棒グラフを確認
9. ✅ [次の問題へ] → 中間リーダーボード（半分経過後）を確認
10. ✅ [最終結果] → 全問終了後の最終ランキングを確認
```

### ステップ 5: 確認事項

各フェーズで以下を確認するよう案内する：
- ホスト・プレイヤー・ディスプレイ画面が同期しているか
- エラーログが出ていないか（サーバーコンソール）
- Bot の回答が正しくカウントされているか

## 補足

- テストは実際のブラウザ操作が必要（ホスト操作はCLIから自動化できない）
- `open-players` と組み合わせて複数プレイヤー画面を開くと確認しやすい
- サーバーログは `dev-server` 起動時のターミナルで確認する
