description: TypeScript型チェックをフロントエンド・サーバー両方実行してエラーを洗い出す
---

フロントエンドとサーバー両方の TypeScript 型チェックを実行し、エラーをまとめて報告します。

## 手順

1. フロントエンドの型チェックを実行する（バックグラウンドではなく同期で）:

```bash
npx tsc --noEmit 2>&1
```

2. サーバーの型チェックを実行する:

```bash
npx tsc --project tsconfig.server.json --noEmit 2>&1
```

3. 結果を以下の形式で整理して報告する:

```
## TypeScript チェック結果

### フロントエンド (tsconfig.json)
- エラー数: N件
- 主なエラー:
  - src/xxx.tsx:行番号 - エラー内容

### サーバー (tsconfig.server.json)
- エラー数: N件
- 主なエラー:
  - server/xxx.ts:行番号 - エラー内容
```

4. エラーがある場合は「修正しますか？」と確認し、修正する場合はエラーの深刻度順（型エラー → 未使用変数）に対応する。

## 注意事項

- `any` の使用は原則禁止（既存コードでやむを得ない場合のみ許可）
- 型定義は `types/game.ts` と `types/events.ts` を参照
- サーバー・クライアント間の型の一貫性を確認する
