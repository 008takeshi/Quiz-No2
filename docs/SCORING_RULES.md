# 得点計算ルール

## 基本コンセプト

このゲームは「正解を当てる」のではなく、「戦略的に選択肢を選ぶ」ゲームです。
正解よりも、**2番目に多く選ばれた選択肢**を選んだプレイヤーの方が高得点を獲得できます。

## 得点配分

| 条件 | 獲得ポイント |
|------|--------------|
| 正解を選択 | 1pt |
| 2位の選択肢を選択 | 2pt |
| 正解かつ2位の選択肢 | 3pt (1pt + 2pt) |

## 詳細ケース

### ケース1: 通常パターン（正解が1位、2位は別の選択肢）

```
問題: 日本の首都は？
正解: 1. 東京

回答結果:
1. 東京: 45人 ← 1位（正解）
2. 大阪: 30人 ← 2位
3. 京都: 15人 ← 3位
4. 名古屋: 10人 ← 4位

得点:
- 東京を選んだ45人 → 各1pt
- 大阪を選んだ30人 → 各2pt ★最も得点が高い
- 京都を選んだ15人 → 各0pt
- 名古屋を選んだ10人 → 各0pt
```

**戦略**: 正解だと思っても、あえて外して2位を狙う方が高得点

---

### ケース2: 2位が複数タイ

```
回答結果:
1. 東京: 40人 ← 1位（正解）
2. 大阪: 20人 ← 2位タイ
2. 京都: 20人 ← 2位タイ
4. 名古屋: 0人

得点:
- 東京を選んだ40人 → 各1pt
- 大阪を選んだ20人 → 各2pt
- 京都を選んだ20人 → 各2pt
- 名古屋を選んだ0人 → 各0pt
```

**重要**: 2位タイの場合、両方の選択肢に2ptを付与します（分配ではない）。
この場合、合計4pt分のポイントが発生します。

---

### ケース3: 2位が3つタイ

```
回答結果:
1. 東京: 40人 ← 1位（正解）
2. 大阪: 20人 ← 2位タイ
2. 京都: 20人 ← 2位タイ
2. 名古屋: 20人 ← 2位タイ

得点:
- 東京を選んだ40人 → 各1pt
- 大阪を選んだ20人 → 各2pt
- 京都を選んだ20人 → 各2pt
- 名古屋を選んだ20人 → 各2pt
```

**重要**: 3つタイの場合、全てに2pt付与（合計6pt分のポイントが発生）

---

### ケース4: 正解が1位かつ2位（正解が独走）

```
回答結果:
1. 東京: 80人 ← 1位（正解）
2. 大阪: 0人
3. 京都: 0人
4. 名古屋: 0人

順位:
1位: 東京 (80人)
2位: 大阪/京都/名古屋 (0人タイ)

得点:
- 東京を選んだ80人 → 各3pt (1pt + 2pt)
- その他を選んだ人 → 各2pt
```

**重要**: 正解が1位かつ2位の場合、正解者には1pt + 2pt = 3ptが付与されます。
また、0人でも2位タイの選択肢には2ptが付与されます。

---

### ケース5: 正解が2位（不正解が1位）

```
回答結果:
1. 大阪: 60人 ← 1位（不正解）
2. 東京: 30人 ← 2位（正解）
3. 京都: 10人
4. 名古屋: 0人

得点:
- 大阪を選んだ60人 → 各0pt
- 東京を選んだ30人 → 各3pt (1pt + 2pt) ★最も得点が高い
- 京都を選んだ10人 → 各0pt
- 名古屋を選んだ0人 → 各0pt
```

**戦略**: 正解が2位になった場合、正解者は最高得点を獲得できる

---

### ケース6: 正解が2位タイの一つ

```
回答結果:
1. 大阪: 40人 ← 1位（不正解）
2. 東京: 20人 ← 2位タイ（正解）
2. 京都: 20人 ← 2位タイ
4. 名古屋: 0人

得点:
- 大阪を選んだ40人 → 各0pt
- 東京を選んだ20人 → 各3pt (1pt + 2pt)
- 京都を選んだ20人 → 各2pt
- 名古屋を選んだ0人 → 各0pt
```

---

### ケース7: 正解が3位以下

```
回答結果:
1. 大阪: 50人 ← 1位（不正解）
2. 京都: 30人 ← 2位（不正解）
3. 名古屋: 15人 ← 3位
4. 東京: 5人 ← 4位（正解）

得点:
- 大阪を選んだ50人 → 各0pt
- 京都を選んだ30人 → 各2pt ★最も得点が高い
- 名古屋を選んだ15人 → 各0pt
- 東京を選んだ5人 → 各1pt
```

**戦略**: 正解がマイナーすぎる場合、2位を狙った方が有利

---

### ケース8: 全員が同じ選択肢を選択

```
回答結果:
1. 東京: 100人 ← 1位（正解）
2. 大阪: 0人 ← 2位タイ
2. 京都: 0人 ← 2位タイ
2. 名古屋: 0人 ← 2位タイ

得点:
- 東京を選んだ100人 → 各3pt (1pt + 2pt)
```

**重要**: 正解が1位かつ2位（タイ含む）の場合は3pt

## 得点計算アルゴリズム

### ステップ1: 各選択肢の投票数をカウント

```typescript
const voteCounts = {
  1: 45,
  2: 30,
  3: 15,
  4: 10
}
```

### ステップ2: 投票数で降順ソート

```typescript
const sorted = [
  [1, 45],  // 1位
  [2, 30],  // 2位
  [3, 15],  // 3位
  [4, 10]   // 4位
]
```

### ステップ3: 2位の投票数を取得

```typescript
const secondPlaceCount = sorted[1][1]; // 30
```

### ステップ4: 2位タイの選択肢を全て抽出

```typescript
const secondPlaceChoices = sorted
  .filter(([_, count]) => count === secondPlaceCount && count > 0)
  .map(([choice]) => choice);
// 結果: [2] または [2, 3] など
```

### ステップ5: 各プレイヤーの得点を計算

```typescript
for (const answer of answers) {
  let score = 0;

  // 正解なら1pt
  if (answer.choice === correctChoice) {
    score += 1;
  }

  // 2位の選択肢なら2pt
  if (secondPlaceChoices.includes(answer.choice)) {
    score += 2;
  }

  playerScores.set(answer.playerId, score);
}
```

## ゲーム戦略

### プレイヤー視点
1. **正解を知っている場合**
   - みんなも知っている → 2位を狙う
   - 自分だけ知っている → 正解を選ぶ

2. **正解がわからない場合**
   - 多数派になりそうな選択肢を避ける
   - 「ちょうど良い」人気度の選択肢を狙う

3. **他プレイヤーの傾向を読む**
   - 前回の結果から、プレイヤーの傾向を分析
   - 心理戦・駆け引きの要素

### ホスト視点
- 簡単すぎる問題 → 全員正解で面白くない
- 難しすぎる問題 → ランダムになる
- **適度な難易度**: 正解が60-70%程度になる問題が理想的

---

## 実装上の注意点

1. **同数判定の精度**: 浮動小数点演算は使わず、整数での比較を行う
2. **0票の扱い**: 0票でも2位タイになる場合は2pt付与
3. **未回答者の扱い**: 未回答者は得点計算の対象外
4. **タイムアウト**: 回答時間切れは未回答扱い（将来的に時間ボーナスを追加する可能性）

---

## 将来的な拡張案

- **早押しボーナス**: 早く回答した人に+0.5pt など
- **連続正解ボーナス**: 3問連続で得点を獲得したら×1.5倍
- **リスクモード**: ダブルポイントで勝負（外れたら0pt）
- **チーム戦**: 4チームに分かれて合計得点を競う
