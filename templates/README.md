# クイズテンプレート集

このディレクトリには、ゲームで使用できるクイズテンプレートが含まれています。

## 利用可能なテンプレート

### 1. default.json
- **タイトル**: デフォルトクイズ
- **問題数**: 10問
- **カテゴリー**: 算数、地理、雑学、理科、スポーツ、IT
- **難易度**: easy (70%), medium (20%), hard (10%)
- **説明**: 基本的な一般知識問題

### 2. geography-japan.json
- **タイトル**: 日本地理クイズ
- **問題数**: 15問
- **カテゴリー**: 都道府県、地形
- **難易度**: easy (53%), medium (27%), hard (20%)
- **説明**: 日本の都道府県、地形、気候に関する問題
- **特徴**: シャッフル機能有効

## テンプレートの使い方

### デフォルトテンプレートとして使用

サーバー起動時に自動的に読み込まれ、ホスト画面で選択可能になります。

### カスタムテンプレートの作成

1. このディレクトリに新しいJSONファイルを作成
2. [QUIZ_TEMPLATE_SPEC.md](../docs/QUIZ_TEMPLATE_SPEC.md) の形式に従って問題を作成
3. サーバーを再起動

## テンプレート形式

```json
{
  "title": "テンプレートのタイトル",
  "description": "説明",
  "version": "1.0",
  "settings": {
    "defaultTimeLimit": 30,
    "shuffleQuestions": false,
    "shuffleChoices": false
  },
  "quizzes": [
    {
      "id": 1,
      "question": "問題文",
      "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "correctAnswer": 0,
      "category": "カテゴリー",
      "difficulty": "easy",
      "explanation": "解説"
    }
  ]
}
```

詳細は [QUIZ_TEMPLATE_SPEC.md](../docs/QUIZ_TEMPLATE_SPEC.md) を参照してください。

## 問題作成のヒント

1. **難易度のバランス**
   - easy: 正解率70%以上を目指す
   - medium: 正解率40-60%を目指す
   - hard: 正解率20-30%を目指す

2. **選択肢の作り方**
   - 明らかに間違っている選択肢を1つ
   - 正解と紛らわしい選択肢を1つ
   - 妥当性がある不正解を2つ

3. **制限時間の目安**
   - 簡単な問題: 15-20秒
   - 普通の問題: 30秒
   - 難しい問題: 45-60秒

4. **このゲームの特性を活かす**
   - 正解が明らかすぎると、みんなが2位を狙う戦略になる
   - 適度に難しい問題の方が、正解と2位が分散して面白い
   - 正解率50-60%の問題が最も盛り上がる

## テンプレートのバリデーション

テンプレートはサーバー起動時に自動的にバリデーションされます。
エラーがある場合は、サーバーログに詳細が出力されます。

### よくあるエラー

- 選択肢が4つでない
- correctAnswerが0-3の範囲外
- 問題文や選択肢が空
- JSON形式が不正
